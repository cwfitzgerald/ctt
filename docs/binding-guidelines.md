## Crate layout

```
crates/ctt-<name>/
├── Cargo.toml
├── build.rs
├── src/
│   ├── lib.rs              # safe Rust API
│   ├── bindings.rs          # single-file bindgen output
│   └── bindings/            # multi-file bindgen output (only if multiple modules needed)
│       └── <name>.rs
├── cpp/ or ispc/            # vendored upstream source (C/C++ → cpp/, ISPC → ispc/)
├── LICENSE-<SPDX>-<NAME>.md
└── prebuilt/                # (ISPC only) prebuilt binary sub-crate
    └── bins/<platform>/     # static libs + sigstore attestations
```

Prefer flat `src/bindings.rs` over a `src/bindings/` directory. Only use a directory when the crate genuinely needs multiple binding modules.

## Naming

- Crates: `ctt-<upstream-name>`
- Prebuilt sub-crates: `ctt-<upstream-name>-prebuilt`
- `Cargo.toml`: workspace-inherit `version`/`edition`/`repository`/`rust-version`/`readme`. Compound SPDX `license`. Use `links` when producing a native static library.

## xtask subcommands

### `cargo xtask vendor [<target>]`

Vendors upstream source into crate directories. Defaults to sibling checkouts; override with `--src <path>`.

| Target | Default source | Destination |
|---|---|---|
| `bc7enc-rdo` | `../bc7enc_rdo` | `crates/ctt-bc7enc-rdo/ispc/` |
| `astcenc` | `../astc-encoder/Source` | `crates/ctt-astcenc/cpp/` |
| `compressonator` | `../compressonator` | `crates/ctt-compressonator/cpp/` |

Only vendor files needed to compile. The compressonator target applies platform patches automatically.

### `cargo xtask generate-bindings`

Regenerates all FFI `.rs` files via bindgen. ISPC crates compile `.ispc` at `-O0` first to get a C header. Requires ISPC.

| Step | Input | Output |
|---|---|---|
| 1/4 | `ctt-astcenc/cpp/astcenc.h` | `ctt-astcenc/src/bindings.rs` |
| 2/4 | `ctt-compressonator/cpp/source/cmp_core.h` | `ctt-compressonator/src/bindings.rs` |
| 3/4 | `ctt-intel-texture-compressor/ispc/kernel.ispc` | `ctt-intel-texture-compressor/src/bindings/kernel.rs` |
| 4/4 | `ctt-bc7enc-rdo/ispc/bc7e.ispc` | `ctt-bc7enc-rdo/src/bindings.rs` |

Generated files are checked in so users don't need bindgen/libclang. Each file starts with a `// Generated by bindgen` header. If ISPC produces anonymous structs (`$anon0`), rename them before bindgen (see `rename_ispc_anon_structs`).

### `cargo xtask build-ispc --crate <target> --target <triple> --output-dir <dir>`

Compiles ISPC source into optimized static libraries. Targets: `intel-texture-compressor`, `bc7enc-rdo`, `both`. Used by CI to produce prebuilt binaries.

### `cargo xtask verify-binaries`

Verifies sigstore attestations on prebuilt ISPC binaries. Requires `gh` CLI.

## Build system

**C/C++ (`cc`)**: Compile vendored source in `build.rs`. Use `.warnings(false)`, appropriate `-std`, `cargo:rerun-if-changed`, and `cc`'s `"parallel"` feature.

**ISPC (`ispc-build-utils`)**: Two mutually exclusive features controlled by `compile_error!` guard:
- `prebuilt` (default) — links prebuilt static libs from companion `-prebuilt` crate
- `build-from-source` — compiles ISPC source (requires ISPC on `PATH`)

For prebuilt binary details, see [prebuilt-binaries.md](prebuilt-binaries.md).

## Safe Rust API principles

- No `unsafe` in public API signatures
- Validate inputs before crossing FFI boundary
- Fallible C APIs → `Result<T, Error>` with `thiserror`; infallible APIs → `assert!`/`panic!` for contract violations
- RAII (`Drop`) for alloc/free lifecycles
- `Send`/`Sync` impls justified with `// SAFETY:` comments
- `Once`/`OnceLock` for one-time init calls
- `#[must_use]` on pure output functions
- Provide both allocating and `_into` (caller-provided buffer) variants

## Checklist for new binding crates

- [ ] Named `ctt-<name>` under `crates/`
- [ ] `cargo xtask vendor` target added
- [ ] Upstream license at `LICENSE-<SPDX>-<NAME>.md`
- [ ] `Cargo.toml`: compound `license`, workspace-inherited fields, `links` if applicable
- [ ] Bindings generated via `cargo xtask generate-bindings` and checked in
- [ ] `build.rs` compiles vendored source
- [ ] (ISPC) Prebuilt sub-crate with mutually exclusive features
- [ ] Safe API, `Result` errors, RAII wrappers, `Send`/`Sync` safety comments
- [ ] Smoke test
